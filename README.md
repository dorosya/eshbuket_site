# EshBuket — Сервис заказов сладких и фруктовых букетов

**EshBuket** — это современный веб-сервис для оформления заказов сладких и фруктовых букетов, тортов и бенто-тортиков. Проект включает **backend на Go + Gin**, **PostgreSQL** для хранения данных, а также будущий **frontend на React**, который позволит удобно просматривать товары и оформлять заказы через красивый интерфейс.

Проект создавался как учебно-практический: одновременно для практики **Go, Docker, DevOps, тестирования и CI/CD**, а также для помощи реальному бизнесу — маме в продаже букетов и тортов.

---

## Функциональность

### Backend (API):
- Авторизация администратора (`POST /api/login`)  
- Управление товарами (`POST /api/products`, `GET /api/products`)  
- Оформление заказов (`POST /api/orders`)  

### Frontend (будущий):
- Отображение всех товаров  
- Фильтры по категориям и цене  
- Оформление заказов через форму  
- Авторизация администратора для управления товарами  

---

## 🛠 Технологии

- **Backend:** Golang + Gin  
- **База данных:** PostgreSQL  
- **Тестирование:** HTTP интеграционные тесты на Go  
- **Контейнеризация:** Docker + Docker Compose  
- **Frontend:** React (планируется)  

---

## Запуск проекта через Docker Compose

1. Склонируйте репозиторий и перейдите в папку backend:

```
git clone <repo-url>
cd backend
```

2. Создайте .env файл с данными администратора:
```
ADMIN_LOGIN=admin
ADMIN_PASSWORD_HASH=$2a$10$...
```

3. Поднимите контейнеры:
```
docker-compose -f http_tests_docker-compose.yaml up --build
```
backend будет слушать 8080 внутри Docker-сети

tests автоматически запускает интеграционные тесты

## Тестирование

Интеграционные тесты находятся в папке tests/

Проверяют работу авторизации, middleware и основных API

Можно запускать вручную:

```
docker-compose run tests
```
